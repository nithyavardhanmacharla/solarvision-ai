## ⚡ Features

- **🌐 Interactive GIS Rooftop Mapper**: High-precision Leaflet map with polygon boundary tracing and automated PV capacity estimation.
- **☀️ Real-Time 3D Simulation**: Interactive Three.js viewport with live solar orbit raytracing, azimuth alignment, and tilt physics.
- **🤖 Solar AI Engineer**: Interactive AI copilot powered by Google Gemini 2.0 Flash for system sizing and engineering analysis.
- **🔋 Battery Storage & Grid Dispatch**: Hourly dispatch simulation, peak-shaving analytics, and self-consumption modeling.
- **📊 Feasibility Reports**: Instant financial models including ROI, LCOE, payback timeline, and CO₂ offset metrics.
- **📱 Mobile-First**: Complete touch gesture isolation and responsive design across all devices.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router) & React 19

- **3D & Maps**: Three.js & Leaflet
- **AI**: Google Gen AI SDK (`@google/genai`)

## 🚀 Quick Start

1. **Clone the repo**:
   ```bash
   git clone https://github.com/nithyavardhanmacharla/solarvision-ai.git
   cd solarvision-ai
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set your API Key** in `.env.local`:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Run locally**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000).
